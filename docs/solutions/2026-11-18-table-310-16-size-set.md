# Table 310.16 "missing" rows were deliberate: they mirror Chapter 9 Table 9 (#272)

**Problem (as filed):** `data/nec/table-310-16.ts` has no 700/800/900 kcmil rows and nothing above 1000 kcmil, so sizing jumps to 750 / 1000 kcmil or to parallel sets.

## What checking the book showed

1. **The rows we have are right.** The NEC 2023 book is in the Obsidian vault (`Electrical Engineering/NEC 2023/Transcript/`). Every stored row (41 rows, Cu and Al, 60/75/90 °C) matches Table 310.16 on p. 70-187.
2. **The gap is Table 9's gap.** The book's Chapter 9 Table 9 lists 14 AWG–1000 kcmil with 600 / 750 / 1000 and no 700 / 800 / 900 or above 1000 kcmil. The sizing tools compute voltage drop from Table 9 for whatever they pick, and a size without a Table 9 row returns 0 V with a CRITICAL warning. So the 310.16 subset is what keeps voltage drop working, and adding the rows would have broken it.
3. **Resolution: guard the invariant.** A comment in the data says why, and `tests/table-310-16.test.ts` fails if the two size sets ever differ. A row added to 310.16 alone fails the test (checked).

## Reusable lessons

- **Before "completing" a table, ask what else keys off its rows.** A deliberate subset with no comment looks exactly like an omission. Write the reason next to the data.
- **The code book is in the vault (NFPA text, OCR'd).** Cross-check garbled cells with the metric line (× 0.3048) or the next column. That's the source CLAUDE.md asks for before any `data/nec` edit.
